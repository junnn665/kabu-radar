# 株価ハック 📡

東証の全上場銘柄（プライム・スタンダード・グロースの内国株式、約3,800社）を監視し、日本株の実データで検証したテクニカルシグナルで「狙い目」をサジェストするWebアプリです。
サーバー不要。GitHub Actions がデータ取得と計算を行い、GitHub Pages で公開します。スマホのホーム画面に追加してアプリとしても使えます。

> ⚠️ 判定・解説は過去データにもとづく機械的なもので、投資助言ではありません。

## 画面

| タブ | 内容 |
|---|---|
| **監視** | 日経平均・TOPIX・S&P500・ドル円と地合い、ウォッチリスト（コードでも銘柄名でも追加可）。銘柄を開くとチャート、損切り/利確の目安、PER/PBR/配当利回り、シグナルの過去成績、「なぜ今？」解説、ニュース、決算・権利落ち警告、価格アラート、売買メモ（書いた時の株価・AI予測と今を比較） |
| **スクリーナー** | 全銘柄から狙い目を抽出。市場区分・33業種・スコア・財務条件（高配当、PBR1倍割れなど）・売買代金で絞り込み |
| **保有株** | 持っている株の評価額・損益、損切り/利確ライン、AI売り候補・売りシグナル・決算の警告。SBI証券などの保有証券CSVを一括取り込み（特定・NISAは合算）、データの無い銘柄は現在値を手入力。業種・銘柄の偏りチェック、配当金の見込み（年間・税引後・権利落ち月）、保有＋ウォッチの決算/権利落ちカレンダー、売買メモ一覧 |
| **ペーパートレード** | サジェスト通りに機械的に売買した場合の実運用ログ（自動記録）と過去1年のシミュレーション |
| **答え合わせ** | 直近8週に「強い買い」だった銘柄が5営業日後どうなったか（週ごと・TOPIX比） |
| **バックテスト** | シグナル別の勝率・市場平均との差、学習に使っていない期間での成績、売買ルール別の成績 |

## AI予測モデル（判定の標準）

毎朝、約3年分・東証全銘柄の日足から、LightGBM で「5営業日後に市場平均（その日の全銘柄平均）をどれだけ上回るか」を学習します。売買代金1億円以上の銘柄・日だけを使い、テクニカル指標・出来高・値動きの大きさ・市場区分・業種など約30項目を入力にしています。

検証は20営業日ごとに「その時点で結果が分かっていたデータだけ」で学び直して次の期間を予測する方法（ウォークフォワード）なので、成績はすべて**学習に使っていない期間**のものです（2025-09〜2026-10、約42万件）。

| | 市場平均との差（5日後） | 勝率 |
|---|---|---|
| AI予測の上位2% | **+0.68%**（8,463回） | 57% |
| 毎日の上位20銘柄 | +0.55% | 57% |
| AI予測の下位2% | −3.05% | — |
| 参考：シグナル点数30以上（3年） | +0.18% | 56% |

予測と結果の順位相関（IC）0.077、上位2%がプラスだった月は86%。4つの設計（全項目／市場全体の項目なし／業種なし／業種内比較）を同じ期間で比べ、最も安定していたものを使っています（`MODEL_VARIANT`）。比較は Actions の「Run workflow」で `experiment` をオンにすると再実行できます。

判定方式は設定で「自動（検証で成績が良い方）／AI予測／シグナル点数」から選べます。

- **判断理由**：銘柄ごとに、予測を押し上げ／押し下げた要因（SHAP 寄与度）を表示
- **本番の答え合わせ**：公開した毎日の予測を記録し、5営業日後の実際の成績（上位2%の市場平均との差・IC）を「答え合わせ」タブで追跡
- **売り時**：保有株のAI予測が下位10%なら「AI売り候補」として警告（下位5%は通知）

- **1か月先の予測**：同じ方法で「20営業日後」を予測するモデルも毎朝学習。ホームの「1週間先／1か月先」で並び順を切り替え、銘柄詳細では両方を表示

AI予測の上位5%から、同じ業種は2銘柄まで・1日5銘柄までを機械的に売買する仮想口座もあります（売買は毎朝、前日の終値で判断）。

## シグナル（v3・日本株向け）

「5営業日後のリターン − 同じ日の全銘柄平均（市場平均との差）」で検証しています。v2 を日本株40銘柄で設計し、東証3,682銘柄・188営業日（約30万件）で検証したうえで、全銘柄では効かなかったものを0点にしました。

| 買い材料 | 点 | 売り・警戒材料 | 点 |
|---|---|---|---|
| 上昇トレンド中の押し目（75日線上向き＋RSI(2)<10） | +25 | 短期の過熱（RSI(2)>90） | −10 |
| 短期の売られすぎ（RSI(2)<10） | +10 | ボリンジャー上限 | −10 |
| ボリンジャー下限 | +10 | 上昇トレンドの急な崩れ（75日線上だが25日線−5%） | −10 |
| 大商いの窓開け上昇（+3%以上で寄り付き・出来高2倍） | +10 | デッドクロス | −10 |
| 5日で−7%以上の急落 | +8 | 出来高を伴う下落 | −10 |
| 上昇トレンド | +5 | 下降トレンド | −5 |

参考表示のみ（0点）：出来高急増・上昇、60日高値ブレイク、下ヒゲ反発、ゴールデンクロス、25日線から+15%以上。

**全銘柄での検証結果（v2・2026年10月時点）**

| | 市場平均との差（5日後） | 勝率 |
|---|---|---|
| 「強い買い」（30点以上） | +0.45%（7,908回） | 55% |
| 学習に使っていない期間（4/9〜10/9） | +0.60%（5,334回） | 54% |
| 答え合わせ（直近8週・TOPIX比） | +0.32% | 55%がTOPIXに勝利 |
| 参考：v1 の答え合わせ | −0.98% | 40% |

- **30点以上「強い買い」／20点以上「注目」／−10点以下「警戒」**
- **売買代金フィルター**：20日平均の売買代金が1億円未満の銘柄はサジェスト・ペーパートレード・成績集計から除外
- **地合い**：日経平均・VIX・ドル円から判定して表示。割り引きフィルターは、相場が悪い日の押し目のほうが成績が良かった（勝率61% vs 52%）ため標準オフ
- **自動チューニング**：毎週、直近120営業日の全銘柄の成績から配点を学び直す（ウォークフォワード）。学習に使っていない期間の成績をバックテストタブで確認できます

## セットアップ

1. **Settings → Pages → Source を「GitHub Actions」**
2. **Actions → Update data & Deploy → Run workflow**（初回は全銘柄1年分の取得で10分ほどかかります）

### 任意の設定（Settings → Secrets and variables → Actions）

| 種類 | 名前 | 用途 |
|---|---|---|
| Secret | `NTFY_TOPIC` | スマホへのプッシュ通知（[ntfy](https://ntfy.sh/) アプリで同じトピックを購読） |
| Variable | `AI_PROVIDER` | `github` で GitHub Models の無料AIを試す（標準はオフ。ルールによる自動まとめを表示） |
| Secret | `ANTHROPIC_API_KEY` | （有料・任意）上位5銘柄の解説を Claude で生成 |

## データの流れ

```
GitHub Actions
  live.yml（取引時間中ずっと動く）
  scripts/live_quotes.py  全銘柄の株価を1分ごとに取得 → live ブランチ（サイトが1分ごとに読む）。10分ごとに pages.yml を起動
pages.yml（平日 朝6時＋取引時間中10分ごと）
  scripts/fetch_data.py   JPX 銘柄一覧・決算発表予定日、日足（朝は yfinance で3年分、日中は live.json から今日の足を作る）・配当・PER/PBR、
                          Google ニュース（上位銘柄）
                          日足は GitHub Actions のキャッシュで引き継ぐ
  scripts/model.py        AI予測（朝は学習と検証、日中は予測のみ）
  scripts/build_data.mjs  判定・バックテスト・ウォークフォワード・ペーパートレード・答え合わせ・解説・通知 → data/
  状態（ペーパートレード等）は data ブランチに保存
  サイト + data/ を GitHub Pages に公開
```

ETF など一覧に入らない銘柄は、サイトの「対象に追加をリクエスト」（Issue「追加: 1306」）で `config/universe_extra.json` に追加できます。

## 注意

- 株価は Yahoo Finance の非公式APIで、約20分遅れです（無料で使える日本株のデータはどこも遅延あり。リアルタイムには証券会社のAPIが必要）。取得できなかった回は公開を更新せず、前回の表示が残ります
- 権利落ち日は配当履歴からの推定で、祝日は考慮していません。PER・PBR は1週間で全銘柄を一巡します
- GitHub の定期実行は、リポジトリに長期間動きがないと止まることがあります（Actions 画面から再開）

## ローカルで動かす

npm start   # http://localhost:3000（データが無ければデモモード）
