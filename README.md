# Kabu Radar 📡

ウォッチリストの株価をリアルタイムで監視し、テクニカル指標から「狙い目」の銘柄を自動でサジェストする静的Webアプリです。サーバー不要で、GitHub Pages でそのまま動きます。

> ⚠️ 判定はテクニカル指標を機械的に採点したもので、投資助言ではありません。

## 機能

- **リアルタイム監視** — デモは数秒ごと、Twelve Data は60秒ごとに価格を更新（値動きをフラッシュ表示）
- **狙い目サジェスト** — 7種類のシグナルを採点（-100〜+100）し、スコア20以上を「今日の狙い目」に表示
- **チャート** — ローソク足・5/25/75日線・ボリンジャーバンド・出来高・RSI（依存ライブラリなし）
- **通知** — 「強い買いシグナル」に変わった時、指定価格を上抜け/下抜けした時にブラウザ通知
- **設定** — ウォッチリスト・アラート・APIキーはブラウザ内（localStorage）にのみ保存
- 上昇色を緑（欧米式）／赤（日本式）で切替、スマホ対応

### 採点ロジック

| シグナル | 点数 |
|---|---|
| RSI < 30（売られすぎ） / < 40 | +25 / +8 |
| RSI > 75（買われすぎ） / > 70 | -20 / -10 |
| ゴールデンクロス / デッドクロス（5日×25日、直近3日） | +25 / -25 |
| ボリンジャー -2σ 以下 / +2σ 以上 | +15 / -10 |
| MACD 好転 / 悪化（直近3日） | +15 / -15 |
| 出来高急増（20日平均の2倍）＋上昇 / 下落 | +15 / -10 |
| 期間高値ブレイク | +10 |
| 上昇トレンド / 下降トレンド（75日線・25日線の向き） | +10 / -10 |

40以上「強い買いシグナル」、20以上「注目」、-30以下「警戒」。ロジックは `js/signals.js` にまとまっているので自由に調整できます。

## データ取得元

| モード | 内容 |
|---|---|
| デモ（既定） | APIキー不要のシミュレーション。日米の主要銘柄 |
| Twelve Data | [twelvedata.com](https://twelvedata.com/) の無料APIキーで米国株の実データ（無料枠: 8リクエスト/分・800/日。自動で制限内に調整） |

画面右上の ⚙ から切り替えます。

## 公開（GitHub Pages）

`main` に push すると GitHub Actions がテスト → Pages へデプロイします。初回だけ **Settings → Pages → Source を「GitHub Actions」** にしてください。

## ローカルで動かす

```bash
npm start   # http://localhost:3000
npm test    # 指標・判定のテスト
```

## 構成

```
index.html
css/style.css
js/app.js         画面・更新ループ・通知
js/providers.js   データ取得（デモ / Twelve Data）
js/indicators.js  SMA・EMA・RSI・ボリンジャー・MACD
js/signals.js     狙い目スコアリング
js/chart.js       Canvasチャート
test/             node:test によるテスト
```
