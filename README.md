# 株価ハック 📡

東証の全上場銘柄（プライム・スタンダード・グロースの内国株式、約3,800社）を監視し、日本株の実データで検証したテクニカルシグナルで「狙い目」をサジェストするWebアプリです。
サーバー不要。GitHub Actions がデータ取得と計算を行い、GitHub Pages で公開します。スマホのホーム画面に追加してアプリとしても使えます。

> ⚠️ 判定・解説は過去データにもとづく機械的なもので、投資助言ではありません。

## 画面

| タブ | 内容 |
|---|---|
| **監視** | 日経平均・TOPIX・S&P500・ドル円と地合い、ウォッチリスト（コードでも銘柄名でも追加可）。銘柄を開くとチャート、損切り/利確の目安、PER/PBR/配当利回り、シグナルの過去成績、「なぜ今？」解説、ニュース、決算・権利落ち警告、価格アラート |
| **スクリーナー** | 全銘柄から狙い目を抽出。市場区分・33業種・スコア・財務条件（高配当、PBR1倍割れなど）・売買代金で絞り込み |
| **保有株** | 持っている株の評価額・損益、損切り/利確ライン、売りシグナル・決算の警告 |
| **ペーパートレード** | サジェスト通りに機械的に売買した場合の実運用ログ（自動記録）と過去1年のシミュレーション |
| **答え合わせ** | 直近8週に「強い買い」だった銘柄が5営業日後どうなったか（週ごと・TOPIX比） |
| **バックテスト** | シグナル別の勝率・市場平均との差、学習に使っていない期間での成績、売買ルール別の成績 |

## シグナル（v2・日本株向け）

日本株の実データで「5営業日後のリターン − 同じ日の全銘柄平均」を測り、期間を前後半に分けても安定していたものを重視しています。

| 買い材料 | 点 | 売り・警戒材料 | 点 |
|---|---|---|---|
| 上昇トレンド中の押し目（75日線上向き＋RSI(2)<10） | +25 | 短期の過熱（RSI(2)>90） | −15 |
| 出来高急増・上昇（20日平均の2倍） | +15 | 上昇トレンドの急な崩れ（75日線上だが25日線−5%） | −15 |
| 大商いの窓開け上昇（+3%以上で寄り付き） | +15 | ボリンジャー上限 | −10 |
| 短期の売られすぎ（RSI(2)<10） | +10 | デッドクロス | −10 |
| ボリンジャー下限 | +10 | 出来高を伴う下落 | −10 |
| 5日で急落・下ヒゲ反発・ゴールデンクロス・60日高値・上昇トレンド | +5 | 25日線から+15%以上・下降トレンド | −5 |

- **30点以上「強い買い」／20点以上「注目」／−10点以下「警戒」**（スコア帯ごとの実績から決定）
- **売買代金フィルター**：20日平均の売買代金が1億円未満の銘柄はサジェスト・ペーパートレード・成績集計から除外
- **地合いフィルター**：日経平均が25日線の下で下向き、前日比−2%以下、VIX25以上、急な円高のとき最大−25点
- **自動チューニング**：毎週、直近120営業日の全銘柄の成績から配点を学び直す（ウォークフォワード）。学習に使っていない期間の成績をバックテストタブで確認できます

v1 で使っていた MACD 好転・RSI(14)<30 は、検証の結果、市場平均に負けていたため外しました。

## セットアップ

1. **Settings → Pages → Source を「GitHub Actions」**
2. **Actions → Update data & Deploy → Run workflow**（初回は全銘柄1年分の取得で10分ほどかかります）

### 任意の設定（Settings → Secrets and variables → Actions）

| 種類 | 名前 | 用途 |
|---|---|---|
| Secret | `NTFY_TOPIC` | スマホへのプッシュ通知（[ntfy](https://ntfy.sh/) アプリで同じトピックを購読） |
| Variable | `AI_PROVIDER` | `none` で GitHub Models の無料AIを止める |
| Secret | `ANTHROPIC_API_KEY` | （有料・任意）上位5銘柄の解説を Claude で生成 |

## データの流れ

```
GitHub Actions（平日 朝7時＋取引時間中15分おき）
  scripts/fetch_data.py   JPX 銘柄一覧・決算発表予定日、yfinance で日足（朝は1年分、日中は直近分）・配当・PER/PBR、
                          Google ニュース（上位銘柄）
                          日足は GitHub Actions のキャッシュで引き継ぐ
  scripts/build_data.mjs  判定・バックテスト・ウォークフォワード・ペーパートレード・答え合わせ・解説・通知 → data/
  状態（ペーパートレード等）は data ブランチに保存
  サイト + data/ を GitHub Pages に公開
```

ETF など一覧に入らない銘柄は、サイトの「対象に追加をリクエスト」（Issue「追加: 1306」）で `config/universe_extra.json` に追加できます。

## 注意

- 株価は Yahoo Finance の非公式APIです。取得できなかった回は公開を更新せず、前回の表示が残ります
- 権利落ち日は配当履歴からの推定で、祝日は考慮していません。PER・PBR は1週間で全銘柄を一巡します
- GitHub の定期実行は、リポジトリに長期間動きがないと止まることがあります（Actions 画面から再開）

## ローカルで動かす

```bash
npm start   # http://localhost:3000（データが無ければデモモード）
npm test    # 指標・判定・バックテスト・データ生成のテスト
```
