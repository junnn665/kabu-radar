# Kabu Radar 📡

日米の株価を監視し、テクニカル指標・バックテスト・AI解説で「狙い目」の銘柄をサジェストするWebアプリです。
サーバー不要。GitHub Actions がデータ取得と計算を行い、GitHub Pages で公開します。スマホのホーム画面に追加してアプリとしても使えます。

> ⚠️ 判定・解説は機械的なもので、投資助言ではありません。

## 機能

| タブ | 内容 |
|---|---|
| **監視** | ウォッチリストの価格・スコア・判定。銘柄を開くとチャート、シグナルごとの過去成績、AI解説、ニュース、決算・権利落ち警告、価格アラート |
| **スクリーナー** | 日米80銘柄（`config/universe.json`）から狙い目を抽出。市場・スコアで絞り込み |
| **ペーパートレード** | サジェスト通りに機械的に売買した場合の実運用ログ（自動記録）と、過去1年のシミュレーション |
| **バックテスト** | シグナルごとの「点灯後5営業日」の勝率・平均リターン、標準配点と自動調整後の配点の比較 |

- **日本株の実データ** — Actions が東証・米国市場の取引時間中に15分おきに Yahoo Finance から取得（約20分遅延）
- **AI「なぜ今？」解説** — シグナル・ニュース見出し・決算日をもとに Claude が3行で整理
- **配点チューニング** — 標準／自動チューニング（過去成績から調整）／カスタム、＋逆張り派・順張り派のスタイル補正
- **決算・権利落ちアラート** — 14日以内はバッジ、3日以内は強調表示＋通知（日本株の権利落ち日は配当履歴から推定）
- **通知** — ブラウザ通知（PWA）、アプリを閉じていてもスマホに届く ntfy 通知

### 採点ロジック（標準配点）

RSI<30 +25 ／ RSI<40 +8 ／ RSI>75 −20 ／ RSI>70 −10 ／ ゴールデンクロス +25 ／ デッドクロス −25 ／ ボリンジャー−2σ +15 ／ +2σ −10 ／ MACD好転 +15 ／ 悪化 −15 ／ 出来高急増・上昇 +15 ／ 出来高を伴う下落 −10 ／ 120日高値ブレイク +10 ／ 上昇トレンド +10 ／ 下降トレンド −10

40以上「強い買いシグナル」、20以上「注目」、−30以下「警戒」。ロジックは `js/signals.js`。

ペーパートレードのルール：スコア40以上で1回¥100,000分を仮想購入 → +10%利確／−5%損切り／スコア−30以下／10営業日で決済（`js/backtest.js` の `DEFAULT_RULES`）。

## セットアップ

1. **Settings → Pages → Source を「GitHub Actions」** に変更
2. **Actions → Update data & Deploy → Run workflow** で初回実行（以降は自動）

### 任意の設定（Settings → Secrets and variables → Actions）

| 種類 | 名前 | 用途 |
|---|---|---|
| Secret | `ANTHROPIC_API_KEY` | 上位5銘柄のAI解説を自動生成（シグナルの組み合わせが変わった時だけ呼ぶので低コスト） |
| Variable | `AI_MODEL` | 既定 `claude-haiku-5-5` |
| Secret | `NTFY_TOPIC` | スマホへのプッシュ通知（下記） |

AI解説は、画面の ⚙ 設定に自分の Anthropic APIキーを入れれば、各銘柄の「AIに聞く」からその場でも生成できます（キーはその端末のブラウザにのみ保存）。

### ntfy 通知（アプリを閉じていても届く）

1. スマホに [ntfy](https://ntfy.sh/) アプリを入れ、推測されにくいトピック名（例 `kabu-radar-x7k2p9`）を購読
2. 同じ名前を Secret `NTFY_TOPIC` に登録

「強い買いシグナル」への変化、ペーパートレードの売買、決算・権利落ち2日前を通知します。

## データの流れ

```
GitHub Actions（15分おき・取引時間中）
  scripts/fetch_data.py   yfinance で日足・決算日・権利落ち日・ニュース取得 → raw/
  scripts/build_data.mjs  判定・バックテスト・ペーパートレード・AI解説・通知 → data/
  data/ を data ブランチに保存（最新1コミットのみ。ペーパートレードの状態を引き継ぐ）
  サイト + data/ を GitHub Pages に公開
```

ブラウザは `data/` を60秒ごとに読み直します。データが無い場合（ローカル実行など）は自動でデモモードになります。

## 注意

- Yahoo Finance のデータは非公式APIのため、仕様変更で取得できなくなることがあります（その場合は前回のデータを表示し続けます）
- 東証の祝日は考慮していないため、権利落ち日の推定がずれることがあります
- GitHub の定期実行は、リポジトリに長期間動きがないと自動停止されることがあります（Actions 画面から再開できます）
- 自動調整後の配点は同じ期間のデータから作るため、バックテスト成績は実際より良く見えます

## ローカルで動かす

```bash
npm start   # http://localhost:3000（デモモード）
npm test    # 指標・判定・バックテスト・データ生成のテスト
```
